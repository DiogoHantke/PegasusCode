# Identidade visual do Pegasus

| Arquivo | Uso |
| --- | --- |
| `pegasus-banner.png` | Banner principal do README |
| `pegasus-logo.jpeg` | Logotipo do projeto |

A identidade do Pegasus combina o cavalo alado com elementos que remetem à pista e aos circuitos do robô, usando preto, azul escuro e azul elétrico. O banner apresenta essa identidade na abertura do README, enquanto os badges mostram a plataforma, a linguagem e o andamento do projeto. O indicador de compilação acompanha o resultado do workflow no GitHub, de forma que sua situação muda conforme as execuções da CI.
